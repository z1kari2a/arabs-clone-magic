# خطة: شاشة "أمر شراء" (ERP) — نسخة طبق الأصل

سأبني نسخة ويب مطابقة للصورة المرفقة بواجهة عربية RTL، بنفس التخطيط والأزرار والحقول والجدول والملخص السفلي.

## النطاق (Frontend فقط، بدون قاعدة بيانات)

الحالة تُدار محلياً في React (useState). لا يوجد حفظ فعلي — الأزرار تعمل على البيانات في الذاكرة.

## التخطيط العام (على `/`)

```text
┌─ شريط العنوان: "أمر شراء" ──────────────────── _ □ × ┐
├─ تبويبات: ملف | أوامر الشراء(نشط) | الموردون | ...  │
├─ شريط أدوات (Ribbon) بأيقونات ملونة:                │
│  جديد | حفظ | نسخ | فتح | تعديل | حذف | بحث |      │
│  طباعة | استيراد Excel | المصاريف | اعتماد | خروج   │
├─ لوحتان جنباً لجنب:                                  │
│  [بيانات المورد]          [بيانات أمر الشراء]        │
├─ جدول الأصناف + أزرار (إضافة صنف، حذف، الوحدات)     │
├─ ملخص أمر الشراء (8 بطاقات إحصائية)                 │
└─ شريط حالة سفلي: المستخدم | الفترة | الاتصال | وقت  │
```

## المكونات

- `src/routes/index.tsx` — الصفحة الكاملة (استبدال placeholder)
- `src/components/erp/TitleBar.tsx` — العنوان + أزرار النافذة
- `src/components/erp/TabsBar.tsx` — تبويبات علوية
- `src/components/erp/Toolbar.tsx` — شريط الأيقونات (lucide-react)
- `src/components/erp/SupplierPanel.tsx` — بيانات المورد
- `src/components/erp/OrderInfoPanel.tsx` — بيانات أمر الشراء
- `src/components/erp/ItemsTable.tsx` — جدول الأصناف (قابل للتعديل)
- `src/components/erp/SummaryCards.tsx` — 8 بطاقات ملخص
- `src/components/erp/StatusBar.tsx` — الشريط السفلي

## وظائف الأزرار (تعمل على state محلي)

- **جديد**: تفريغ النموذج ورقم أمر جديد
- **حفظ**: إشعار toast + تثبيت البيانات
- **نسخ**: نسخ الأمر الحالي برقم جديد
- **فتح / بحث**: Dialog باختيار رقم أمر (بيانات وهمية)
- **تعديل**: تفعيل وضع التحرير على الحقول
- **حذف**: تأكيد ثم مسح
- **طباعة**: `window.print()` بستايل طباعة نظيف
- **استيراد Excel**: input file يقرأ CSV/XLSX عبر مكتبة `xlsx` ويعبّئ الجدول
- **المصاريف**: Dialog لإدخال المصاريف الإضافية (يؤثر على متوسط التكلفة)
- **اعتماد**: تغيير حالة الأمر إلى "معتمد" + قفل الحقول
- **خروج**: العودة للصفحة الرئيسية / تنبيه
- **إضافة صنف / حذف صف / الوحدات**: تعديل صفوف الجدول

## جدول الأصناف

أعمدة (RTL، من اليمين): م، الموديل، الباركود، اسم الصنف، الوحدة، العبوة، الكراتين، الكمية، سعر الشراء، إجمالي الشراء، CBM، إجمالي CBM، تكلفة الكرتون، متوسط التكلفة.

- صفوف بيانات وهمية مطابقة للصورة (5 أصناف)
- صف مجاميع في الأسفل يُحسب تلقائياً
- تعديل مباشر داخل الخلايا (contentEditable/inputs)

## بطاقات الملخص (8 بطاقات)

إجمالي الأصناف، إجمالي الكراتين، إجمالي الكمية، إجمالي قيمة الشراء، إجمالي CBM، إجمالي المصاريف، سعر CBM الواحد، إجمالي التكلفة، متوسط التكلفة — كل بطاقة بأيقونة ملونة كما في الصورة.

## التصميم (design tokens في `src/styles.css`)

ألوان مطابقة لواجهة Windows ERP:
- خلفية عامة: رمادي فاتح `#f0f2f5`
- شريط العنوان: أزرق داكن `#1e5a8e`
- Ribbon: أبيض مع حدود رمادية
- ترويسات الأقسام: تدرج أزرق فاتح
- خلايا مميزة: أصفر باهت `#fff8dc`
- خط: Cairo أو Tajawal (Google Fonts عبر `<link>` في `__root.tsx`)
- `dir="rtl"` على `<html>`

## تفاصيل تقنية

- إضافة حزمة `xlsx` لاستيراد Excel: `bun add xlsx`
- تحميل خط Cairo عبر `<link>` في `__root.tsx` (وليس `@import` في CSS)
- تحديث `head()` في `index.tsx` بعنوان "أمر شراء - نظام ERP" ووصف مناسب
- تصميم responsive أساسي لكن مُحسّن لسطح المكتب (الصورة سطح مكتب)
- shadcn Dialog / Toast / Button للتفاعلات

## ملاحظات

- الأسماء والأرقام العربية والبيانات الوهمية مطابقة للصورة
- المناطق الملونة بالأخضر في الصورة (تمويه) ستُترك فارغة أو ببيانات عامة
