# شرح ملفات المشروع وتشغيلها

مرجع تفصيلي لكل ملف ومجلد: **ما وظيفته**، و**كيف تشغّله**، و**متى تعدّله**.
للدليل الوظيفي (الشاشات والمعادلات) راجع [الدليل-الكامل.md](الدليل-الكامل.md).

---

## أولاً: كيف تشغّل المشروع

### 1. التشغيل لأول مرة على جهاز جديد

```bash
git clone <رابط-المستودع>
cd arabs-clone-magic
npm install                 # تنزيل المكتبات (يقرأ package.json)
npm run dev                 # تشغيل وضع التطوير
```

يفتح على `http://localhost:8080`. أي تعديل في `src/` ينعكس فوراً بلا إعادة تشغيل.

> إذا لم يوجد ملف `.env` انسخ `.env.example` إليه — النظام يعمل بدونه، لكن
> النسخ الاحتياطي السحابي وخدمات التراخيص تحتاجه.

### 2. تشغيل نسخة الإنتاج محلياً

```bash
npm run build                          # يبني إلى مجلد .output
PORT=8080 node .output/server/index.mjs
```

### 3. النشر على السيرفر (fikradigital.online)

```bash
./scripts/deploy.sh
```

بناء ← `pm2 restart erp` ← فحص أن الموقع يرد 200 قبل إعلان النجاح.

### 4. نسخة سطح المكتب (Electron)

```bash
npm run electron:start        # تشغيل مباشر للتجربة
npm run electron:build:win    # ملف تنفيذي لويندوز → electron-release/
npm run electron:build:linux  # ملف تنفيذي للينكس
npm run shell:start           # نسخة القشرة المحمية بالترخيص
npm run bundle:build          # حزمة مشفّرة تُنزَّل عبر خادم التراخيص
```

### 5. أوامر الصيانة

| الأمر              | الوظيفة                           |
| ------------------ | --------------------------------- |
| `npm run lint`     | فحص الأخطاء وأسلوب الكود          |
| `npm run format`   | تنسيق كل الملفات                  |
| `npx tsc --noEmit` | فحص الأنواع (TypeScript) بلا بناء |
| `npm run preview`  | معاينة نسخة الإنتاج               |

## ثالثاً: مجلد `src/` — قلب النظام

### `src/lib/` — المنطق والبيانات ★

| الملف                                                               | الوظيفة                                                                                                                                                                                        |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`erp-store.ts`** ★★                                               | **محرّك الحساب والتخزين.** فيه `computePO` التي تحسب كل شيء: عدد الطرود، إجمالي CBM، سعر CBM، توزيع المصاريف، التكلفة النهائية. **أي تعديل على المعادلات يكون هنا فقط** — ينعكس على كل الشاشات |

| `auth.ts`                                                           | الحسابات والدخول والصلاحيات (`canWrite` / `canDelete` / `canApprove`) وموافقة المدير على التسجيلات                                                                                             |

## سادساً: قواعد مهمة قبل التعديل

1. **المعادلات في مكان واحد** — `computePO`. لا تكرّر حساباً داخل شاشة، وإلا تتناقض الشاشات.
2. **`routeTree.gen.ts` مولَّد** — لا تحرّره؛ يتحدّث تلقائياً عند إضافة ملف في `routes/`.
3. **التخزين عبر `local-db.ts` فقط** — لا تكتب في `localStorage` مباشرة من أي شاشة.
4. **افحص قبل النشر:** `npx tsc --noEmit` ثم `./scripts/deploy.sh` (السكربت لا يعلن النجاح إلا بعد أن يرد الموقع فعلاً).
5. **نقطة حفظ قبل أي تعديل كبير:** `git add -A && git commit -m "وصف"` — وللتراجع `git revert <رقم>`.
