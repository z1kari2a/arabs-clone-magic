# نسخة محمولة — ويندوز (بدون تثبيت)

|          |                                             |
| -------- | ------------------------------------------- |
| التشغيل  | `ERP.exe`                                   |
| النظام   | Windows 10/11 — 64 بت                       |
| الإصدار  | 1.0.1                                       |
| الحجم    | 349 ميغابايت                                |
| الإنترنت | غير مطلوب — البرنامج يعمل بالكامل بلا اتصال |

## الاستخدام

انسخ المجلد كاملاً إلى الجهاز (أو إلى فلاشة) ثم شغّل `ERP.exe` مباشرة. لا حاجة إلى تثبيت
ولا صلاحيات مدير.

> يجب نسخ **المجلد بكل محتوياته**. تشغيل `ERP.exe` وحده لا يعمل — البرنامج يحتاج مجلدات
> `resources` و `locales` وملفات `.dll` المجاورة له.

## أول تشغيل

تظهر شاشة **«أول تشغيل: أنشئ حساب المدير»** — لا توجد كلمة مرور افتراضية. الحساب الأول
الذي تنشئه يصبح المدير بصلاحيات كاملة.

## البيانات

قاعدة البيانات تُنشأ في `%APPDATA%\erp\erp.db`، وليست داخل هذا المجلد — أي أن حذف المجلد
أو استبداله بإصدار أحدث لا يمسّ البيانات. النسخ الاحتياطي التلقائي يُحفظ في
`%APPDATA%\erp\backups` عند كل تشغيل وكل 6 ساعات (آخر 14 نسخة).

## التحميل من GitHub

الملفات الثنائية الكبيرة مخزّنة عبر Git LFS. زر **Download ZIP** في GitHub **لا** يجلبها —
سيعطيك ملفات نصية صغيرة بدل البرنامج. استنسخ المستودع بدلاً من ذلك:

```bash
git lfs install
git clone https://github.com/z1kari2a/arabs-clone-magic.git
```

## البديل: مثبّت بنقرة واحدة

إن كنت تفضّل التثبيت العادي مع اختصار على سطح المكتب، استخدم
`../ERP-Desktop-Windows/ERP-Setup-1.0.1.exe`.
