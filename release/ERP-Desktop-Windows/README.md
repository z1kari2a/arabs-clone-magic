## أول تشغيل

عند فتح البرنامج لأول مرة تظهر شاشة **«أول تشغيل: أنشئ حساب المدير»** — لا توجد كلمة مرور
افتراضية. الحساب الأول الذي تنشئه يصبح المدير بصلاحيات كاملة.

قاعدة البيانات تُنشأ تلقائياً في `%APPDATA%\erp\erp.db`، وتُؤخذ نسخة احتياطية عند كل تشغيل
وكل 6 ساعات داخل `%APPDATA%\erp\backups`. إزالة البرنامج لا تحذف هذه البيانات.

## التثبيت

1. حمّل `ERP-Setup-1.0.7.exe` من هذا المجلد.
2. شغّله بالضغط المزدوج. إذا ظهرت نافذة SmartScreen اختر **More info** ثم **Run anyway** (المثبّت غير موقّع رقمياً).
3. اتبع خطوات المثبّت — يُنشئ اختصاراً على سطح المكتب وفي قائمة ابدأ.

## التحديثات

بعد التثبيت لا حاجة لتحميل نسخة جديدة من هنا مرة أخرى: البرنامج يتحقق من
الإصدارات الجديدة بنفسه، ينزّلها في الخلفية، ثم يعرض **«تحديث جاهز — إعادة
التشغيل الآن»**. الموافقة تكفي؛ يظهر طلب صلاحية المدير (UAC) مرة واحدة، ثم يعود
البرنامج مفتوحاً على الإصدار الجديد وبياناتك كما هي.

- للتحقق يدوياً: **مساعدة ← التحقق من وجود تحديث…**
- لإيقاف التحديث التلقائي: **الإعدادات ← تحديثات البرنامج**
- على جهاز بلا إنترنت: لا يظهر شيء ولا يتأخر البرنامج — التحقق يفشل بصمت.

## التحقق من سلامة الملف

في PowerShell:

```powershell
Get-FileHash .\ERP-Setup-1.0.7.exe -Algorithm SHA256
```

يجب أن تطابق النتيجة قيمة SHA-256 أعلاه.

## إعادة البناء من المصدر

```bash
npm install
npm run build:electron     # يبني الواجهة إلى dist-electron
node scripts/make-win.mjs  # يحزّم التطبيق إلى electron-release/ERP-win32-x64
node scripts/make-installer.mjs  # ينتج المثبّت ERP-Setup-1.0.7.exe
```

ناتج البناء يظهر في `electron-release/` وهو مجلد مستثنى من Git؛ هذا المجلد (`release/`) يحتفظ بالنسخة الجاهزة للتوزيع فقط.
